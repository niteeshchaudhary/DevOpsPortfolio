# SCENE_03_PIPELINE_NETWORK.md

> Scene: 03 — Pipeline Network
>
> Duration: ~40–60 seconds (depending on scroll speed)
>
> Position: After Source Control, before the CI/CD Factory
>
> Environment: Pipeline Valley → Automation Junction → Factory Entrance
>
> Purpose:
>
> Show how a simple Git webhook evolves into a fully automated CI/CD pipeline. This scene introduces the idea that pipelines are intelligent infrastructure carrying software through multiple validation stages before it reaches production.

---

# Scene Overview

The webhook signal from the Git Control Facility disappears into the mountains.

Moments later, deep underground machinery awakens.

Massive valves begin rotating.

Pressure builds.

Transparent industrial pipelines illuminate with flowing blue "code-water."

Thousands of glowing particles rush through the network.

The visitor realizes:

**Automation has started.**

This valley is the circulatory system of the entire DevOps world.

Nothing is built manually anymore.

# Parallel Pipeline Animation

At approximately 25% scroll,

one pipeline becomes five.

Each branch runs independently.

Some finish quickly.

Others continue processing.

The completed branches wait at synchronization gates.

No pipeline advances until every required dependency has completed.

This visually teaches dependency management.

# Learning Objective

By the end of Scene 03, visitors should naturally understand:

* A Git push automatically starts a CI/CD pipeline.
* Multiple jobs execute in parallel.
* Some stages depend on others before continuing.
* Pipelines produce reusable build artifacts.
* Failures are detected, isolated, and repaired automatically.
* Notifications and monitoring happen throughout execution.
* Automation is not a single script—it is a living network of coordinated systems.

The visitor should leave this scene feeling that they have watched software flow through an intelligent industrial pipeline rather than a series of abstract CI/CD stages.
